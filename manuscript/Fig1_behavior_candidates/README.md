# Figure 1 behavior candidates

This folder stages the data-backed BehavioralDynamics panels for a revised E9 Figure 1 story. It is intentionally a candidate set rather than a frozen final figure.

## Proposed story

1. **Outcome definition** — show later `CombZ` / integrated resilience as the endpoint used to contextualize CON/RES/SUS. This is phenotype definition, not independent validation.
2. **First perturbation response** — show the first 12 h active-phase movement trajectory after CC1.
3. **Prospective feature associations** — show the fixed a priori Stage 09 features (`Movement_mean`, `Movement_rmssd`, `Entropy_acf1`) against later `CombZ`.
4. **Prospective prediction** — show the fixed behavior-only model registry and cross-validated performance, rather than relying on a simple pooled correlation.
5. **Held-out predictions** — show leave-one-animal-out predicted versus observed `CombZ` for the headline movement model and the fixed three-feature supporting model.
6. **Longitudinal phenotype** — show a conservative raw-movement cage-change x phase characterization as the current safe longitudinal panel.

The existing experimental-design schematic can remain upstream of these panels; it is not generated by BehavioralDynamics and is therefore not duplicated here.

## Important status

The core candidate set uses canonical Stage 03, Stage 09, Stage 16 outputs and the Stage 14 first-active raw movement trajectory. Run the current pipeline before staging so the folder reflects the corrected Stage 09 active-only window and complete endpoint identity matching.

The broader Stage 14 systems candidates (repeated adaptation, active/inactive systems heatmap, rest/quiescence architecture) are listed in `figure_manifest.csv` but are **not copied by default**. Active Stages 11 and 12 and the shared duration helper still contain permissive `active|dark|night` matching that can classify `Inactive` as active. Those panels should only be staged after that classifier is fixed and the affected stages are rerun.

## Build

From the repository root:

```r
source("manuscript/Fig1_behavior_candidates/build_fig1_candidates.R")
```

By default the script reads the E9 behavior project from:

```text
S:/Lab_Member/Tobi/Experiments/Exp9_Social-Stress/Analysis/Behavior/RFID
```

Override this without editing the script by setting:

```text
MMM_BEHAVIOR_PROJECT_ROOT
```

Generated SVG/PDF files are written to:

```text
manuscript/Fig1_behavior_candidates/rendered/core/
```

A `staging_status.csv` is written alongside them so missing or stale upstream products are visible rather than silently ignored.

## Core panel files

- `01_outcome_definition.*` — generated from the canonical Stage 16 animal-level source data; no inferential RES/SUS brackets.
- `02_first_active_movement_trajectory.*` — Stage 14 first-active trajectory.
- `03_primary_feature_associations.*` — Stage 09 three-feature prospective association panel.
- `04_primary_prediction_cv.*` — Stage 09 behavior-only repeated-CV model registry.
- `05_heldout_prediction.*` — generated from the canonical Stage 16 LOAO prediction source data.
- `06_longitudinal_movement.*` — Stage 03 cage-change x phase raw movement characterization.

The final manuscript assembly should use only the subset that makes one coherent claim; this folder deliberately keeps alternatives available for comparison.
