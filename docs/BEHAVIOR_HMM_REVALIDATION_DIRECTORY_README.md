gap-aware audits run against the activated current Stage 01 and Stage 08
inputs. The 9-file input/code roster was hash-checked before and after the
audits. The Step 6 comparison retained direction in 13/13 compared cells.

exhaustive search over HMM optima.

was nominally significant in 0/5 fits and remains excluded as a finding.
Inactive-phase interpretation remains blocked by tracking measurement
validity. No manuscript registry, Stage 16 product, or release was refreshed
from these tables.
